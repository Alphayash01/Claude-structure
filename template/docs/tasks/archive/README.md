# Archived Tasks

> **Purpose:** Finished task files, moved here when their task is done. They are a record of how the work happened.

Files keep the name they had while active, so searching for the issue number still finds them.

**Never edit an archived file.** Lasting facts already live in the permanent docs. For follow-up work, open a new issue and a new task file that links back here. The full process is in [docs/tasks/README.md](../README.md).
